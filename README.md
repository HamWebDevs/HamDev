# HamDev — independent web design

A lightweight static website portfolio for Anthony Fulton, based in West Cumbria.

## Pages
- `/` — homepage, package prices and live showcase links
- `/brief.html` — customer questionnaire that formats an enquiry for the user to copy to Messenger
- `/examples/stone/` — fictional tradesperson concept
- `/examples/still/` — fictional barber studio concept
- `/examples/northline/` — fictional car detailing concept

## Deployment
For Cloudflare Pages, connect `HamWebDevs/HamDev` to a new Pages project. Set production branch `main`, build command blank, output directory `/`. Static HTML, CSS and JavaScript: no Node or build tools required.

The repository can also be hosted on any static host supporting its intended commercial usage. Custom domain and form email delivery require independent configuration.

## Pricing shown
First three customers: £20 (one page), £60 (up to three), £105 (up to five). Standard prices £35, £75, £120. Design only. Optional managed static hosting from £5/month; domain additional. Update the offer manually once the three slots are filled.

## What the enquiry form does
It stays entirely in the customer's browser until they choose to copy or download a message. No submission endpoint, email collection, login, payment processor, database or third-party analytics. The customer must send the enquiry manually.

## Important notes
- Showcase businesses and copy are clearly labelled fictional. No invented reviews or clients.
- Don't request customer passwords, financial information or account credentials through the questionnaire.
- Agree scope, timescales, revisions, deposit and handover terms in writing.
- Configure and verify a form delivery provider before selling a live contact form.
- Check the current terms of a host before using it for commercial customer websites.
