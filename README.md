# HamDev — Independent Web Design

Affordable, considered websites for small businesses in West Cumbria and across the UK.

Site by Anthony Fulton. Introductory offers for first three customers: one-page £20, three-page £60, five-page £105. Domain and optional managed hosting separate.

This repository contains a personal portfolio, an enquiry questionnaire and three clearly labelled fictional showcase websites. No framework or build pipeline is necessary.

## Deployment

Connect this repository to Cloudflare Pages. Use its static HTML settings: no build command, output directory `/`. Open the `brief.html` page for customer enquiries. Deployments should be previewed and tested before client use.

No passwords or payment details should be requested through the enquiry form. Confirm scope, pricing, revisions, hosting and launch conditions directly with each customer.
